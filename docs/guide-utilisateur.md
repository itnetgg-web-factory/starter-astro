# Guide utilisateur : modifier votre site

Ce guide explique comment modifier les textes, les images et les tarifs de votre site, puis publier ces modifications. Aucune connaissance technique n'est nécessaire.

## Les trois règles à retenir

1. **Publiez, puis vérifiez en ligne.** Vous pouvez préparer plusieurs éléments en brouillon, puis les publier l'un après l'autre ; vérifiez chacun sur le site. Plusieurs champs d'un même élément (par exemple le prix et la description d'une même formule) partent dans une seule publication.
2. **Comptez 3 minutes** entre la publication et l'affichage sur le site.
3. **En cas de refus, ne recommencez pas indéfiniment.** Attendez 2 minutes et réessayez **une seule fois**. Si le refus persiste, arrêtez-vous et contactez votre prestataire (voir [En cas de problème](#en-cas-de-problème)). Votre modification n'est pas perdue.

## Se connecter

1. Ouvrez l'adresse de votre site suivie de `/admin/`. Par exemple : `https://www.votre-site.fr/admin/`.
2. Cliquez sur **Se connecter avec GitHub**.
3. Une fenêtre s'ouvre : connectez-vous avec votre compte GitHub (identifiant, mot de passe, puis code de double authentification).
4. La première fois seulement, GitHub vous demande d'autoriser l'application du site : cliquez sur **Authorize**.

Vous arrivez sur la page **Contenus**. La connexion reste valable environ 8 heures. Ensuite, le site vous demande de vous reconnecter.

Si la fenêtre de connexion ne s'ouvre pas, autorisez les fenêtres surgissantes (pop-ups) pour votre site dans le navigateur.

## Modifier un contenu

Dans **Contenus**, la colonne de gauche regroupe les éléments du site :

| Rubrique | Ce que vous y modifiez |
|---|---|
| Réglages du site | Nom, coordonnées, liens du menu et du pied de page |
| Page d'accueil | Titre principal, textes des sections, galerie d'images |
| Étapes et prestations | Chaque prestation : titre, description, liste des livrables |
| Formules et tarifs | Chaque formule : nom, prix, période, description, avantages |
| Témoignages | Citations de vos clients |
| Pages simples | Mentions légales, politique de confidentialité |

1. Choisissez la rubrique, puis l'élément à modifier.
2. Modifiez les champs du formulaire. Le résultat se vérifie sur le site, une fois publié.
3. Les champs obligatoires sont signalés. Certains textes ont une longueur maximale : un message vous l'indique si vous la dépassez.

### Remplacer une image

1. Sous l'image, cliquez sur **Choisir une image différente**, puis téléversez votre fichier.
2. Formats acceptés : JPEG, PNG ou WebP, de préférence moins de 2 Mo. Le site crée lui-même les tailles adaptées aux écrans.
3. Avant l'envoi, donnez à votre fichier un nom simple, sans espaces ni caractères spéciaux : `atelier-printemps.jpg` plutôt que `Photo atelier (2) !.jpg`.
4. Remplissez le **texte alternatif** : une courte phrase qui décrit l'image pour les personnes malvoyantes et les moteurs de recherche. Exemple : « Atelier de poterie baigné de lumière ».

## Enregistrer

Cliquez sur **Enregistrer** en haut de la page. Le message « Entrée enregistrée » s'affiche.

Votre modification est enregistrée comme **brouillon** : elle n'est pas encore visible sur le site. Vous pouvez fermer la page et y revenir plus tard. Vos brouillons sont listés dans l'onglet **Flux**.

## Publier

1. Après l'enregistrement, ouvrez le menu **Statut** en haut de la page et choisissez **Prêt**.
2. Attendez environ **1 minute** : le site vérifie automatiquement votre modification.
3. Cliquez sur **Publier**, puis sur **Publier maintenant**, et confirmez.

Le message « Entrée publiée » confirme la publication.

**Si la publication est refusée** (message « Échec de la publication… ») :

- juste après l'enregistrement, c'est normal : la vérification automatique n'est pas terminée. Attendez 2 minutes et cliquez à nouveau sur **Publier maintenant** ;
- si le refus revient, **arrêtez-vous** et contactez votre prestataire. Ne supprimez pas votre brouillon et ne refaites pas la modification : une intervention technique est nécessaire, et votre travail sera conservé.

## Vérifier le résultat

1. Environ **3 minutes** après la publication, ouvrez votre site dans un nouvel onglet (ou cliquez sur **Voir en direct**).
2. Rechargez la page pour afficher la dernière version :
    - sur ordinateur : `Ctrl` + `Maj` + `R` (Windows) ou `Cmd` + `Maj` + `R` (Mac) ;
    - sur téléphone : tirez la page vers le bas.
3. Vérifiez votre modification sur ordinateur et, si possible, sur téléphone.

Si elle n'apparaît toujours pas 10 minutes après la publication, contactez votre prestataire.

Vous pouvez alors passer à la modification suivante.

## En cas de problème

Contactez votre prestataire en indiquant :

- ce que vous vouliez modifier (par exemple : « le prix de la formule Accompagnement ») ;
- le message affiché, idéalement avec une capture d'écran ;
- l'heure approximative.

Votre site reste en ligne pendant ce temps : une publication refusée ne modifie rien sur le site.
